# Dynamic Anti-Proxy QR Attendance & Defaulter Alert System

A JavaFX desktop and web-integrated application designed to eliminate proxy attendance in academic institutions
using time-based encrypted QR codes and automated email notifications.

## Tech Stack
* **Language:** Java 25 (OpenJDK)
* **UI Framework:** JavaFX
* **Database:** SQLite
* **Security:** SHA-256 Hashing / TOTP Dynamic Tokens
* **Libraries:** ZXing (QR processing), JavaMail API, Javalin (HTTP Server)
